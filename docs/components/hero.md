# Hero

**Component ID:** LYT-04  
**Entry point:** `@pranxy/zordon-ui/hero`

Hero provides CSS-only directives for the documented hero container, content, and overlay parts.

```html
<section zdHero class="min-h-screen" aria-labelledby="hero-title">
  <div zdHeroOverlay></div>
  <div zdHeroContent class="text-center">
    <div><h1 id="hero-title">Launch</h1></div>
  </div>
</section>
```

Consumers own host semantics, background media, headings, content order, responsive utilities, actions, loading, video controls, animation, and accessibility labels. The directives add no roles, focus behavior, state, or ARIA attributes.
