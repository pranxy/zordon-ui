# Tooltip manual accessibility review

Status: Pending. No human accessibility pass is claimed.

Record tester, date, OS, browser, assistive technology, steps and results for:

- Screen-reader host names and descriptions, preserving existing descriptions and avoiding duplicate announcements.
- Interactive dialog naming, F2 discovery, native actions, Forms, Tab boundaries and focus restoration.
- Tooltip inside Dropdown: top-only Escape, controlled rejection and parent destruction.
- Hover persistence, pointer travel into rich help, disabled wrappers and physical touch long press/cancellation.
- Light/dark contrast, forced colors, reduced motion, RTL, zoom/reflow and long translated help.
- Essential help availability without JavaScript and behavior during hydration.

Chromium axe and synthetic input checks are automated evidence, not physical-device or assistive-technology review.
