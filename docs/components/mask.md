# Mask

**Component ID:** LYT-07  
**Entry point:** `@pranxy/zordon-ui/mask`

`ZdMask` applies daisyUI’s mask classes to a native image or consumer-owned element.

```html
<img zdMask shape="circle" alt="Avery Chen" src="/avery.jpg" />
```

`shape` supports every daisyUI shape; `half` supports `half-1` and `half-2`. Native image alternatives, loading, sizing, object fit, fallback content, and semantics remain consumer-owned. The directive adds no ARIA, state, or interaction behavior.
