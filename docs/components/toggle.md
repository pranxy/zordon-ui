# Toggle

**Component ID:** INP-13  
**Entry point:** `@pranxy/zordon-ui/toggle`

`ZdToggle` styles a native checkbox as a daisyUI toggle.

```html
<label for="notifications">Enable release notifications</label>
<input id="notifications" type="checkbox" zdToggle color="primary" size="lg" />
```

The browser owns checked state, keyboard interaction, disabled state, Forms integration, validation, labels, and serialization. Consumers own switch wording, descriptions, icons, loading policy, and any indeterminate policy.
