# Textarea

**Component ID:** INP-12  
**Entry point:** `@pranxy/zordon-ui/textarea`

`ZdTextarea` styles a native `<textarea>` with daisyUI colors, sizes, and ghost styling.

```html
<label for="notes">Release notes</label>
<textarea id="notes" zdTextarea color="primary" size="lg" rows="4"></textarea>
```

The browser owns value editing, rows, resize behavior, constraints, validation, Forms integration, and serialization. Consumers own labels, descriptions, auto-grow policy, character counts, masks, debounce, and field composition.
